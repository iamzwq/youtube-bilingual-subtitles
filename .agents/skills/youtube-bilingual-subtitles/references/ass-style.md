# ASS 双语字幕样式说明

`build_ass.py` 生成的字幕采用以下约定，本文档解释每个关键项，便于按需微调。

## Script Info

| 项                      | 值              | 说明                                                                              |
| ----------------------- | --------------- | --------------------------------------------------------------------------------- |
| `PlayResX` / `PlayResY` | `1920` / `1080` | 字号 `fs60`/`fs36` 按 1080p 像素渲染；libass 会自动把该虚拟分辨率缩放到实际帧尺寸 |
| `WrapStyle`             | `0`             | 智能自动换行（超长行自动平衡折行）                                                |
| `ScaledBorderAndShadow` | `yes`           | 缩放时底框/边框随分辨率等比缩放                                                   |

## 样式 Bilingual

```
Style: Bilingual,霞鹜文楷等宽,36,&H00FFFFFF,&H000000FF,&H26000000,&H00000000,
       0,0,0,0,100,100,0,0,3,6,0,2,80,80,60,1
```

| 字段          | 值             | 说明                                                      |
| ------------- | -------------- | --------------------------------------------------------- |
| Fontname      | `霞鹜文楷等宽` | 霞鹜文楷等宽；未安装则 libass 回退系统默认字体            |
| Fontsize      | `36`           | 基准字号（原文行）；中文行用内联 `{\fs60}` 放大           |
| PrimaryColour | `&H00FFFFFF`   | 文字白色（`AABBGGRR`，AA=00 不透明）                      |
| OutlineColour | `&H26000000`   | **底框颜色**（黑）+ 透明度：AA=`0x26`≈38 → 约 0.85 不透明 |
| BackColour    | `&H00000000`   | 阴影色（Shadow=0，未使用）                                |
| BorderStyle   | `3`            | 不透明底框模式（与“字形描边”互斥，二选一）                |
| Outline       | `6`            | 底框相对文字的内边距                                      |
| Shadow        | `0`            | 不要投影                                                  |
| Alignment     | `2`            | 底部居中                                                  |
| MarginV       | `60`           | 距底边距离                                                |

## 双语行

每条字幕为单个 Dialogue 事件，中文在上、原文在下：

```
{\fs60}中文译文\N{\fs36}原文
```

非语音内容（`[Music]` 等）译文为空时，只显示原文行 `{\fs36}原文`。

## 底框颜色的渲染器差异（重要）

`BorderStyle=3` 下，libass / Aegisub 用 **OutlineColour** 填充底框；旧版 VSFilter 可能改用 BackColour。若在目标 ffmpeg 上烧录后**底框未上色**，把同样的 `&H26000000` 也写到 `BackColour` 再试。建议正式烧录前先截取 10 秒小样确认。

## 透明度换算

ASS alpha：`00`=完全不透明，`FF`=完全透明。目标不透明度 `p` → alpha = `round((1 - p) * 255)`。

- 0.85 不透明 → `(1-0.85)*255 ≈ 38 = 0x26`
