# ASS 双语字幕样式说明

`build_ass.py` 生成的字幕采用以下约定，本文档解释每个关键项，便于按需微调。

## Script Info

| 项                      | 值              | 说明                                                                              |
| ----------------------- | --------------- | --------------------------------------------------------------------------------- |
| `PlayResX` / `PlayResY` | `1920` / `1080` | 字号 `fs60`/`fs36` 按 1080p 像素渲染；libass 会自动把该虚拟分辨率缩放到实际帧尺寸 |
| `WrapStyle`             | `0`             | 智能自动换行（超长行自动平衡折行）                                                |
| `ScaledBorderAndShadow` | `yes`           | 缩放时底框/边框随分辨率等比缩放                                                   |

## 样式 CN / EN

中文与原文各用一个独立样式，分别是一个独立的 Dialogue 事件，在底部堆叠：

```
Style: CN,霞鹜文楷等宽,60,&H00FFFFFF,&H000000FF,&H26000000,&H00000000,0,0,0,0,100,100,0,0,3,6,0,2,80,80,131,1
Style: EN,霞鹜文楷等宽,36,&H00FFFFFF,&H000000FF,&H26000000,&H00000000,0,0,0,0,100,100,0,0,3,6,0,2,80,80,60,1
```

| 字段          | CN / EN 值     | 说明                                                      |
| ------------- | -------------- | --------------------------------------------------------- |
| Fontname      | `霞鹜文楷等宽` | 未安装则 libass 回退系统默认字体                          |
| Fontsize      | `60` / `36`    | 中文 60 在上，原文 36 在下                                |
| PrimaryColour | `&H00FFFFFF`   | 文字白色（`AABBGGRR`，AA=00 不透明）                      |
| OutlineColour | `&H26000000`   | **底框颜色**（黑）+ 透明度：AA=`0x26`≈38 → 约 0.85 不透明 |
| BackColour    | `&H00000000`   | 阴影色（Shadow=0，未使用）                                |
| BorderStyle   | `3`            | 不透明底框模式（与“字形描边”互斥，二选一）                |
| Outline       | `6`            | 底框相对文字的内边距                                      |
| Shadow        | `0`            | 不要投影                                                  |
| Alignment     | `2`            | 底部居中（实际定位由每条事件的 `\pos` 覆盖，见下）        |
| MarginV       | `131` / `60`   | 样式内的边距值已被 `\pos` 覆盖，仅作回退，不再实际生效    |

## 双语行

每条字幕拆成**两个独立 Dialogue 事件**（中文用 `CN` 样式、原文用 `EN` 样式），并给每条事件加**固定锚点 `\pos` + 对齐 `\an`** 来定位：

```
Dialogue: 0,<start>,<end>,CN,,0,0,0,,{\an2\pos(960,949)}中文译文
Dialogue: 0,<start>,<end>,EN,,0,0,0,,{\an8\pos(960,963)}原文
```

- **中文**：`\an2`（底边居中锚点）钉在 `y=949`，多行时**向上生长**，永远在上。
- **原文**：`\an8`（顶边居中锚点）钉在 `y=963`，多行时**向下生长**，永远在下；两者留 ~14px 间隙不重叠。
- **为什么用 `\pos` 而不是只靠 MarginV**：libass 默认开启碰撞检测（Collisions=Normal），当原文过长折成两行、底框向上膨胀撞到中文时，libass 会**自动重排事件位置，导致中文/原文上下互换**。给事件加 `\pos` 会禁用该事件的碰撞重排，锚点固定后中文永远在上、原文永远在下。
- 坐标常量集中在 `build_ass.py` 顶部（`CENTER_X/CN_BOTTOM_Y/EN_TOP_Y`），需要整体上移/下移或调间距时改这里。

之所以拆两个事件而非单事件内联 `{\fs60}...\N{\fs36}...`：单事件中不同字号会被 libass 当作独立渲染段，各自绘制半透明底框并在交界处**上下重叠**，叠加后那一条背景明显变深。拆成两个事件、各自 `\pos` 定位即可避免。

非语音内容（`[Music]` 等）译文为空时，只输出 `EN` 一行。

## 底框颜色的渲染器差异（重要）

`BorderStyle=3` 下，libass / Aegisub 用 **OutlineColour** 填充底框；旧版 VSFilter 可能改用 BackColour。若在目标 ffmpeg 上烧录后**底框未上色**，把同样的 `&H26000000` 也写到 `BackColour` 再试。建议正式烧录前先截取 10 秒小样确认。

## 透明度换算

ASS alpha：`00`=完全不透明，`FF`=完全透明。目标不透明度 `p` → alpha = `round((1 - p) * 255)`。

- 0.85 不透明 → `(1-0.85)*255 ≈ 38 = 0x26`
